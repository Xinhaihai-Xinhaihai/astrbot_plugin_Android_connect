v0.3.0 预发布：手机插件控制面板与横屏桌面。

- 控制页新增插件管理，按已启用／已停用分类，可切换第三方插件开关；需在电脑端允许手机插件管理。
- 独立横屏／竖屏桌面，持续刷新画面、画质选择、虚拟按键、中文输入。
- 接入 Android USB／蓝牙键鼠，手柄摇杆和按键映射到电脑键鼠，可修改常用手柄按键映射。
- 按键按住／松开有序传递，退出、外设断开、失焦、授权撤销或心跳超时自动释放；失败不重放。
- 530 / 1033 和 502 显示具体 Tunnel 排障提示。
- 保留 1／5／10／一直任务模式、新对话修复和单轮重复操作保护。

请先更新电脑插件到 v0.3.0，再覆盖安装 APK。插件管理总开关默认关闭，在电脑端配置中开启后重载。

已通过后端测试及 Android 模拟器的插件开关、横屏、虚拟键、外接键盘和手柄映射检查。测试使用模拟硬件与本地模拟接口，不代表所有手机、手柄和游戏实机验证。

桌面当前使用 JPEG 画面（最高约 4 FPS），无音频或低延迟视频串流。手柄为键鼠映射，不是原生 Xbox 手柄透传；部分游戏或高权限窗口可能拒绝模拟输入。

下载 APK 安装到 Android 8.0+；插件 ZIP 适用于 Windows 原生 AstrBot 4.29.4+。MIT License。
