首版预发布：Windows AstrBot 插件 + Android 配套 APK。

- 四个页面：聊天、任务、控制、设置。
- 局域网自动发现、6 位一次性配对码。
- Cloudflare 临时与固定域名连接向导。
- 手机消息驱动 AstrBot 内置 AI；支持电脑操作和反向手机操作。
- 电脑、手机分别授权；限时开关、任务取消、紧急停止、操作记录。
- MIT 协议；完整中文 README。

下载 APK 安装到 Android 8.0+；插件 ZIP 安装到 Windows 原生 AstrBot 4.29.4+。先按 README 完成配对，再开启设备控制。

这是 v0.1.0 预发布，尚需不同手机厂商和真实模型环境验证。手机无障碍、通知及后台运行权限需要手动授权。首版不绕过锁屏，不含定时任务或视频串流。
