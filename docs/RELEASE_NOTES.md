# v0.4.0 — 全屏视频与手机配置中心

请同时更新电脑插件和 APK。保持同一签名，可覆盖安装；连接密钥和聊天记录保留。

- 新增 H.264 桌面视频：30／60 FPS 目标档位、1280／1920px，显示手机实际解码帧率；适用于局域网和 Cloudflare Tunnel。保留截图兼容模式。电脑编码需要新依赖 imageio-ffmpeg 0.6.0。
- 桌面默认全屏、工具条自动隐藏，可切换横竖屏、适应或铺满。
- 虚拟按键支持添加、删除、拖动、改大小、组合键、整体与单键透明度，布局自动保存。
- 手机“控制 → 插件与 AstrBot 配置”新增插件配置、全局配置方案及人格编辑。支持表单与 JSON、保存前校验、冲突检测和电脑备份。
- 插件配置保存后可重载第三方插件；全局配置需重启 AstrBot 后完整生效。控制台登录安全和连接权限设置继续由电脑管理。
- 断线、编辑布局、切到后台、视频故障或授权到期时释放按键并关闭捕获进程。

## 首次使用

1. 电脑插件更新到 v0.4.0，安装 requirements.txt 新依赖并重载。
2. 配置中打开“允许手机编辑插件和 AstrBot 全局配置”；插件开关管理使用原来的独立开关。
3. 手机覆盖安装新版 APK；打开遥控面板，在菜单“画质 / 刷新率”选择 60 FPS。
4. 自定义按键在菜单“编辑按键 / 添加按键 / 按键透明度”；完成布局后恢复控制。

60 FPS 是目标帧率，受电脑、手机和网络影响。开发电脑 1280×720 编码实测 4 秒 239 帧。当前无音频；手柄仍为键鼠映射，不是 Windows 虚拟 Xbox 手柄。
