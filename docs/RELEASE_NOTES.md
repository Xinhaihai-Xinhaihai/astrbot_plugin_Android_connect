v0.2.0 预发布：增加任务次数模式和单轮重复操作保护。

- 聊天页选择 1 次、5 次、10 次、一直；默认 1 次，发送成功后恢复默认。
- 插件逐轮调度，显示完成次数、等待状态及每轮结果，轮次间默认等待 5 秒。
- 单轮完成后及时结束；重复设备指令或动作循环触发拦截与停止。
- 重试不增加轮次；失败、超时、停止、授权失效或重启后不自动重跑。
- 修复撤销权限时的队列竞争，当前轮与后续轮同时停止。
- 增加后端次数／停止／迁移测试，以及手机四种次数模式的提交与停止检查。
- 请先更新电脑插件到 v0.2.0，再覆盖安装 APK。已有任务记录自动迁移，手机连接配置保留。

下载 APK 安装到 Android 8.0+；插件 ZIP 安装到 Windows 原生 AstrBot 4.29.4+。先按 README 完成配对，再开启设备控制。

这是 v0.2.0 预发布，尚需不同手机厂商和真实模型环境验证。手机无障碍、通知及后台运行权限需要手动授权。当前版本不绕过锁屏，不含定时触发或视频串流。
