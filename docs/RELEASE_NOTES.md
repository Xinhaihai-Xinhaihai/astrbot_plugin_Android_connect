# v0.5.0 — 鼠标遥控修复与独立配置中心

电脑插件和 APK 请一起更新。APK 与旧版保持同一签名，可覆盖安装。

- 手机控制页分为两个入口：**AstrBot 配置**、**插件管理**。全局配置按模型、消息平台、对话与 Agent、语音、知识库等类别组织；人格单独管理。
- 模型和平台列表支持逐项表单编辑、添加与删除，保留高级 JSON。中文字段说明、选项说明与原始配置键和值分开，避免翻译改变配置。
- 鼠标默认使用触摸板模式：滑动移动，轻点在当前指针位置点击，长按后拖拽，双指轻点右键，双指滑动滚动。可切换触屏定位，调节灵敏度。
- 鼠标与键盘改用带鉴权的 WebSocket 实时输入，合并移动并限制积压；断线、退出、失焦或授权结束释放按键。旧版电脑接口仍有 HTTP 兼容模式。
- 修复细小鼠标移动丢失、Windows 显示缩放坐标偏移、组合键修饰键顺序。新增电脑指针位置标记，截图模式也能看到。
- 支持锁定外接鼠标进行相对移动，Esc 或切换窗口释放；保留全屏、30/60 FPS 视频、自定义虚拟按键、键鼠和手柄键位映射。

## 更新后怎么用

1. 更新电脑插件并重载，再覆盖安装 APK。
2. 手机“控制 → 打开 AstrBot 配置”编辑本体；“打开插件管理”修改插件开关和插件配置。
3. 遥控桌面菜单“鼠标与触控”设置触摸方式与灵敏度。默认触摸板模式轻点不会让指针跳位。
4. 修改列表后依次点击“应用到列表 → 应用到草稿 → 保存到电脑”。全局配置保存后需重启 AstrBot，插件可单独重载。

这是预发布版本。手柄经过模拟输入验证，仍需真实手柄和游戏验证；当前为键鼠映射，不提供 Windows 虚拟 Xbox 手柄。公网网络延迟不能通过提高目标视频帧率消除。
