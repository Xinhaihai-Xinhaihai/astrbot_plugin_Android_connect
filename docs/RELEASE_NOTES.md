v0.1.2 预发布：修复“新对话”点击后看起来没有反应的问题。

- 新建后显示“新对话已创建”，清空旧草稿并聚焦输入框；任务页保留旧记录。
- 未连接时提供明确的连接说明和“前往连接设置”入口。
- 消息提交期间禁用新建，避免对话切换与网络响应交错；提交期间新写的草稿会保留。
- 模拟器新增新对话、历史记录和延迟响应的回归检查。
- 补全阿里云等注册商域名接入 Cloudflare 的步骤，更新手机向导和 README。
- APK 可覆盖安装 v0.1.0 / v0.1.1，保留本机连接配置。

下载 APK 安装到 Android 8.0+；插件 ZIP 安装到 Windows 原生 AstrBot 4.29.4+。先按 README 完成配对，再开启设备控制。

这是 v0.1.2 预发布，尚需不同手机厂商和真实模型环境验证。手机无障碍、通知及后台运行权限需要手动授权。当前版本不绕过锁屏，不含定时任务或视频串流。
