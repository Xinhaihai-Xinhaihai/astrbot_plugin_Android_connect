# v0.6.0 — 横竖屏切换与公网 IPv4 直连

电脑插件和 APK 请一起更新。APK 与旧版保持同一签名，可覆盖安装。

- 聊天页面、草稿、任务次数、设备权限、设置地址和滚动位置在横竖屏切换后保留。
- 插件管理、AstrBot 全局配置和配置编辑器适配配置变化；未保存的配置输入不会因旋转丢失。
- 桌面遥控旋转时保留当前会话、输入连接和焦点，不再通过断开重连完成布局。
- 虚拟按键按横屏、竖屏分别保存坐标；大小、透明度和键位定义在两个方向同步，删除按键会同时清理两套布局。旧版布局会在升级后迁移。
- 新增公网 IPv4 HTTP 直连。公网 HTTP 默认关闭，需要 APK 显式允许；HTTP 只接受数字 IPv4，HTTP 域名仍被拒绝，HTTPS 域名可正常使用。
- 补充路由器 TCP 8765 端口转发、Windows 防火墙、公网 IPv4 查询、CGNAT 和 DDNS 说明。
- 扩展 Android 35 模拟器检查：横竖屏状态恢复、配置草稿、独立虚拟按键布局、旋转后输入会话保持，以及公网 IPv4 校验。

## 连接前怎么选

- **同一 Wi-Fi**：地址填电脑局域网 IP，例如 `http://192.168.1.10:8765`。
- **公网 IPv4 直连**：插件监听 `0.0.0.0`，路由器转发 TCP `8765`，Windows 防火墙放行 TCP `8765`；APK 勾选允许公网 HTTP，再填 `http://公网IP:8765`。
- **离开家庭网络**：优先使用 Cloudflare Tunnel，手机填写 `https://你的域名`。

连接密钥来自电脑插件的 `api_token` 或一次性配对码。GitHub PAT 只用于代码仓库，不能用于 APK 连接。公网 HTTP 会暴露明文聊天、密钥、截图和遥控输入；服务器返回 401 时重新配对，怀疑泄露时立即更换电脑端密钥。

这是预发布版本。不同手机厂商的旋转策略、后台限制、外接设备、路由器和公网网络仍需按实际环境验证。
