# 使用与权限

## 最小验证步骤

1. 安装插件和 APK，配对成功。
2. 所有设备控制保持关闭，聊天发送“你好”。确认模型响应。
3. 电脑总开关开启 → APK 电脑授权 1 小时 → 发送“截取电脑当前画面并描述内容”，勾选电脑。
4. 打开电脑遥控面板，刷新截图；确认画面内容与主屏幕一致，再试一个无副作用点击。
5. 手机总开关开启 → 手机手动授权无障碍及通知 → APK 手机授权 1 小时 → 勾选手机，要求“返回桌面并告诉我可访问的应用名称”。
6. 点紧急停止，确认新设备操作被拒绝、手机授权不自动恢复。

## 权限组合

| 任务 | 电脑插件总开关 | APK 限时授权 | 消息勾选 |
| --- | --- | --- | --- |
| 普通聊天 | 无 | 无 | 两项均不选 |
| 电脑 Agent | allow_desktop_control | 电脑开启 | 电脑 |
| PowerShell | allow_desktop_control + allow_shell | 电脑开启 | 电脑 |
| 手机 Agent | allow_phone_control | 手机开启 + 系统无障碍 | 手机 |
| 双设备任务 | 两个设备总开关 | 两个设备均开启 | 两项均选 |

每次工具执行都重新检查权限。电脑关闭后取消关联任务；手机本地关闭立即拒绝新操作。紧急停止不能撤销已经完成的副作用。

电脑键鼠本身能打开应用和终端；关闭 PowerShell 工具不是操作系统沙箱。仅对可信主人开启设备控制。手机也只应配对你自己的 AstrBot。

## 会话和任务

- 点击“新对话”会创建独立会话、清空输入框、显示“新对话已创建”并唤起输入；任务页仍保留旧会话的执行记录。
- 未连接时可以先创建对话，点击“前往连接设置”完成配对后再发送消息。
- 消息提交期间暂时禁用“新对话”，成功或失败后恢复。发送期间写入的下一条草稿不会被延迟返回的响应清空。
- 同一电脑一次执行一个任务，最多等待 32 个任务。
- 网络超时时再次发送相同待提交消息会复用请求 ID，避免重复创建任务。
- 插件重启不自动执行旧任务，防止重复写入、点击或发送。
- 任务没有定时触发功能，睡前任务是立即提交后在电脑端继续执行。
- 电脑端日志包含技术错误；APK 返回经过简化的错误原因。
