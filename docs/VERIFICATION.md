# 首版验证记录

日期：2026-11-04（Asia/Shanghai）。

## 已完成

- Python 服务端测试：鉴权、非法输入、幂等提交、会话隔离、取消后继续执行、授权过期、手机指令路由、双向停止、重启不重放。
- 配对测试：默认关闭、一次使用、有效期及错误次数限制。
- 停止测试：旧的手机授权轮询不能在紧急停止后自动恢复控制。
- AstrBot 4.29.4 真实 SDK 导入与事件构建；使用替代模型响应验证聊天/工具分支和运行时 PowerShell 开关检查。
- JDK 17 / SDK 35 签名 APK 编译与 Android Lint。
- Android 35 x86_64 模拟器安装 APK，打开聊天、任务、控制、设置四个页面，验证导航和连接地址校验，导出截图进行目视检查。

本地 Python 完整测试为 12 项通过（含真实 SDK 接口测试）；不安装 AstrBot 的轻量 CI 会跳过 SDK 测试。

## 仍需使用者环境验证

- 用户真实 AstrBot 模型的回答、工具调用能力和视觉理解效果。
- 用户路由器的 mDNS 发现、Wi-Fi/AP 隔离、防火墙规则。
- 用户 Cloudflare 域名和隧道的实际可达性。
- 不同 Android 厂商的无障碍、后台和电池策略。
- 真实手机上目标应用的界面可访问性，以及 Windows 桌面/UAC/显示缩放的效果。

模拟器页面检查不等于真实手机端到端控制测试。因此首版按预发布提供，不能视为已在所有设备完成无人值守验证。
